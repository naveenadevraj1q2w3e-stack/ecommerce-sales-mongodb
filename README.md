# E-commerce Sales Analysis using MongoDB

This project performs e-commerce sales analysis using MongoDB aggregation pipelines.

## Database

- Database: `ecommerce_db`
- Collection: `sales`
- Tool: MongoDB Compass

## Analyses Performed

1. Sales by Category
2. Top Selling Products
3. Sales by City
4. Sales by Payment Method
5. Monthly Sales
6. Top Customers
7. Total Revenue

## Aggregation Pipelines

| File | Analysis |
|---|---|
| `01_Sales_by_Category.js` | Total sales by category |
| `02_Top_Selling_Products.js` | Top 5 products by quantity sold |
| `03_Sales_by_City.js` | Top 5 cities by sales |
| `04_Sales_by_Payment_Method.js` | Sales by payment method |
| `05_Monthly_Sales.js` | Monthly sales |
| `06_Top_Customers.js` | Top 5 customers by sales |
| `07_Total_Revenue.js` | Total revenue |

## Technologies

- MongoDB
- MongoDB Compass
- MongoDB Aggregation Framework
- JavaScript
